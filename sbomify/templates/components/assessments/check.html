{% comment %} One compliance check inside an open assessment row: its outcome, title, explanation and, when the plugin gives one, how to fix it. Checks sit in a plain list divided by hairlines. They are not boxed, because the row they hang from is already inside the one frame the section has. status is the plugin's outcome (fail, error, warning, pass, info). A failed check takes the warning ink and an error the danger ink, the same mapping as the row's verdict, and the outcome is written out for a screen reader. The slot is the explanation; remediation is shown after it as the fix. {% endcomment %}
