{% comment %} One assessment as a row in the artifact's assessment list: its verdict, name, outcome bar and a reason, with its checks opening directly underneath. The list is the only frame. Rows are divided by hairlines and the details are not boxed again, so the section reads as one document rather than cards in cards. tone (danger, warning, info, success, neutral) picks the verdict's icon and ink; label is the verdict in words, so colour never carries it alone. caption is the short reason beside the bar ("6 of 7 checks passed", "1 critical, 2 high", why a run was skipped). segments and bar_label go to c-assessments.bar. stale is the plugin's current version, set when the run came from an older one: it adds "Out of date", and the badge names the version to re-run on. state is the Alpine expression that reads true while the row is open, the same contract as c-cards.collapsible-trigger: it drives aria-expanded, turns the chevron and shows the details slot. The caller supplies the click handler, since only it knows whether one row or many may be open. Attributes land on the trigger button, which is where an id or a click handler belongs. Without state the row does not open: it renders the same line as plain text and the named action slot takes the chevron's place, for an assessment that has nothing to show yet (queued, or never run here) and a Run control instead. A button cannot hold another button, so the two cannot share an element. anchor is the row's own id, for links such as #plugin-ntia that land on it. The details run flush to the list's edges, as a table does in c-tables.shell: the toolbar, table and footer inside carry their own gutters and bands, and anything else placed there brings its own padding. A hairline separates them from the row that opened them. {% endcomment %}
