{% comment %} One artifact's assessments as a single table cell: a proportional bar of the runs' outcomes, how many passed, and a written line of everything else ("6 failed, 1 skipped"). It replaces a run of truncated per-plugin pills, whose failure icon read as a remove button and whose "+N" hid the very runs that failed. The plugins that did not pass are named in the tooltip and to a screen reader, so nothing is lost by folding them into one cell. Rows are built by Alpine, so the caller passes bind, the expression for the row's assessment data ("item.assessments"), whose plugins list carries one {display_name, status} per run. status is pass, fail, error, pending or skipped. A skipped run neither passed nor failed, so it stays out of the passed fraction and is only reported. The caller decides what a row with no runs says; this renders runs. {% endcomment %}
