{% comment %} The shell every badge shares, in plain Tailwind utilities. Pages use a variant component (c-badges.primary and friends); those nest this and pass their recipe through variant_class. Shape and size render as one conditional segment, and the corner radius as another, so utilities never stack against each other. shape="severity" is the squarer, uppercase scale shape used by c-badges.severity. Without a variant_class the shell is the neutral tint the bare tw-badge was. type renders the shell as a button, for the badge that is a control: the re-run beside an assessment run's metadata is a badge you press, and a styled span with a click handler would be neither focusable nor disableable. c-badges.action is that badge; every other variant stays a span. The two branches differ only in the element and in the disabled affordance a span cannot carry, and must stay in lockstep. {% endcomment %} {% if type %} {% else %} {{ slot }} {% endif %}
