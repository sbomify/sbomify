{% comment %} The shell every branded button shares. Pages use a variant (c-branded.buttons.primary and friends); those nest this and pass their recipe through variant_class. With an href it renders an anchor, so any variant works as a link, and the two branches differ only in element and must stay in lockstep. data-button is not decoration. These render on public pages, where the legacy stylesheet repaints every anchor from the workspace accent unless the anchor is excluded, and [data-button] is the exclusion. A branded anchor without it comes out the wrong colour on the only pages this library is used. Sizes and radii avoid the legacy utility names: .rounded-lg, .shadow-sm, .p-4 and friends are !important on those pages and would win. See the class-name rule in AGENTS.md; a render test enforces it. {% endcomment %} {% if href %} {{ slot }} {% else %} {% endif %}
