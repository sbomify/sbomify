A quiet line of text with an optional icon, so a row of these reads as one sentence of context rather than a set of buttons. Anything that is a status the reader should spot without reading is a c-branded.badge instead, and sits in the same row. mono is for identifiers (versions, CVE ids) that a reader copies, where the fixed-width face says "this is a value" and keeps digits from shifting. label names the value in words, muted, with the value after it in a stronger ink: "CVSS 8.6", "CVE IDs CVE-2026-0001". A bare identifier or number gives a reader nothing to go on, and an icon only works for the few facts that have an obvious one. With a label, mono applies to the value alone. The value's wrapper is display: contents, so its parts sit in the item's own wrapping row: several identifiers break between one another, the first staying beside its label, rather than the whole list dropping to a line of its own.
