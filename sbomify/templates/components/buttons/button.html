{% comment %} The shell every text button shares, in plain Tailwind utilities. Pages use a variant component (c-buttons.primary and friends); those nest this and pass their recipe through variant_class. With an href it renders an anchor, so any variant works as a link. Size renders as one conditional segment so utilities never stack against each other. The two branches below differ only in element and must stay in lockstep. A button is never underlined, at rest or on hover. The public pages load a legacy `a:hover { text-decoration: underline }`, and a bare element-plus-pseudo selector outranks a plain `no-underline` class, so the hover state has to be stated too. Tailwind loads after those sheets, so the tie goes to the utility. Every button marks itself data-button. The public base still carries the pre-Tailwind link rules that repaint any anchor on the page, and their exclusion list was a list of tw-* class names; the marker is what a library button is recognised by now that it carries none. The default size's radius is written 0.5rem rather than `rounded-lg`, which computes the same: the public base also loads static/css/utilities.css, whose `.rounded-lg` is an !important 0.75rem and would round every button there. {% endcomment %} {% if href %} {{ slot }} {% else %} {% endif %}
