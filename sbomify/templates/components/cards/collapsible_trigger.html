{% comment %} The header row that opens and closes a collapsible card. A real button, so the keyboard reaches it and screen readers get aria-expanded. state is the Alpine expression that reads true while the panel is open; it drives aria-expanded and turns the chevron over. The caller supplies the click handler that flips it, because only the caller knows whether the stack allows one open panel or many. The slot is the title row. bare puts the slot straight into the row instead of wrapping it in that title. A header that is a plugin's name plus its status chips and a muted finding count builds its own line, and the bold ink belongs to the name inside it, not to everything standing beside it. The two branches differ only in that wrapper and must stay in lockstep. {% endcomment %}
