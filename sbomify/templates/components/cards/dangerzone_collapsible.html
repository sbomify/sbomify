{% comment %} The Danger Zone, assembled: the band that is also the control that opens it, and the collapsing body the destructive rows go in. Every page's danger zone composes this one component, so the band, the chevron and the keyboard behaviour cannot drift apart per page. They did once, three ways. The band reads before it warns: a danger icon chip, the title in danger ink, and a quiet line saying what the zone is, all on the ordinary header wash. The subtitle is a prop with a default so every zone explains itself the same way; pass subtitle to say something more specific. The hover tint is here rather than on the parts because only this band is a control. state names the caller's boolean that is true while the zone is open. It defaults to isExpanded, which is what dangerZone() in alpine-components.ts provides, so most callers pass nothing. The trigger flips it by assignment, the way c-modal derives its dismiss from show, so a caller supplies state and never a handler. The chevron matches c-cards.collapsible-trigger: muted ink on the right edge, down while shut, turned over while open. One collapsing motion across the app, danger or not. The rows are the slot, landing on c-cards.dangerzone-body so the collapse sits on the padded element itself; the confirm modal a row opens belongs to the caller, next to this tag, because only the caller knows what it deletes. {% endcomment %}
