{% comment %} A block of code with a copy control. code is a prop, not the slot: whitespace inside a pre element is content, and a slot would fold the template's own indentation into the snippet. language names the highlighter class the page's highlighter looks for. The bar holding the copy control is one element with two recipes: with a filename it is the header band above the code, without one it is a box in the block's top-right corner. That keeps a single copy button in the file rather than one per placement, and it means the control stays put while a capped block scrolls under it. The copied state repaints background, border and text at once, so it renders as one complete Alpine binding rather than a class layered over the resting one: two utilities for the same property would be resolved by stylesheet order, not by which is "on". The focus ring is the library floor; the tw-* rules never had one here. {% endcomment %}
