{% comment %} The standalone copy control: a labelled button that puts value on the clipboard and confirms in place for two seconds. label and copied_text are props rather than the slot because the button reads as one string or the other depending on its own state, which a slot cannot express. Both are server-rendered as well as bound, so the resting label is on the page before Alpine reaches it. The copied state repaints background, border and text at once, so it renders as one complete Alpine binding rather than a class layered over the resting one: two utilities for the same property would be resolved by stylesheet order, not by which is "on". The icons are two elements rather than one swapped class, so each carries its own colour and neither has to fight the other's. The focus ring is the library floor; the tw-* rule never had one. {% endcomment %}
