{% comment %} The popover panel a menu, an option list or a small form sits on. Open state and positioning stay with the caller, which supplies x-show, the transitions, x-ref and ::style (cotton's escape for Alpine's :style); this owns the surface, the menu semantics and the roving keyboard handling. flush drops the inset padding so sections and option lists run to the edge, and it owns overflow, so scrolling content goes on an inner element. floating switches to fixed positioning for a menu teleported to the body and caps it to the viewport. Position, padding and overflow render as two conditional segments so a flush floating panel still gets exactly one of each. role defaults to menu, which is what brings aria-orientation and the arrow, home and end key handling; pass role="" for a panel that is not a menu. The keys match on the menuitem prefix, so a row that is a choice rather than a command (menuitemradio, menuitemcheckbox) is stepped through with the rest of them. {% endcomment %}
