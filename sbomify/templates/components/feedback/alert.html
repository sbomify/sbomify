{% comment %} An inline notice, in plain Tailwind utilities. The four alerts differ only by their accent colour, which the CSS carried as --alert-accent, so variant is a prop, not four files: one conditional segment sets that custom property and every tinted utility below reads it. The message is the slot; title is a prop. dismissible keeps its Alpine hook, retargeted at the data-alert root now that the alert no longer carries a tw-* class. The named action slot is the control that resolves the notice: it sits after the message as the row's last item, where a status alert wants its "Set up" or "Manage" link. It is a slot, not a prop, so the control is a real button component; give it shrink-0 so a long message cannot squeeze it. The named body slot replaces that paragraph for a notice that explains itself at length: several paragraphs, a preformatted scanner error, a refresh button. A block element inside the paragraph would be closed out of it by the parser, so the two are one branch and never both render. The named mark slot replaces the glyph, for the notice whose mark is not one: a scan still running takes the brand loader, which is an include and not a Font Awesome class. Also one branch, so an alert never carries two marks. {% endcomment %}
