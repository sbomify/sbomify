{% comment %} An inline notice with a quiet, solid tint and neutral text. One accent property colours the surface, border and mark for all four variants. The message is the slot; title is a prop. A 24px line box centres the glyph without a manual offset. Titled notices align the mark with the heading; plain notices centre it beside the message, including when that message wraps. The named action slot holds a real button component in its own grid column. When the alert is narrow, it moves below the message with the same left edge. Dismissible notices reserve room for the shared icon button and keep the Alpine hook on the data-alert root. The named body slot replaces that paragraph for a notice that explains itself at length: several paragraphs, a preformatted scanner error, a refresh button. A block element inside the paragraph would be closed out of it by the parser, so the two are one branch and never both render. The named mark slot replaces the glyph, for the notice whose mark is not one: a scan still running takes the brand loader, which is an include and not a Font Awesome class. Also one branch, so an alert never carries two marks. {% endcomment %}
