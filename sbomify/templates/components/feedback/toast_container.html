{% comment %} The live region every toast lands in. Pages never build a notification by hand: they dispatch a `toast` event with { type, title, message, duration } and this container renders it. The live rows compose c-feedback.toast. Only their text, icon and dismissal come from Alpine; the shared toast owns sizing and appearance. The container is a singleton the base template renders once, so it takes no props: it owns its own corner of the viewport and needs no placement from a caller. {% endcomment %}
