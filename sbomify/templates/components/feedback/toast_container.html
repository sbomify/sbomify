{% comment %} The live region every toast lands in. Pages never build a notification by hand: they dispatch a `toast` event with { type, title, message, duration } and this container renders it. The surface below repeats the recipe in c-feedback.toast because Alpine builds it in the browser from the event payload, so there is nothing for the server-rendered component to wrap. The two must move together: the static utilities are identical, and only the accent, the icon glyph and the text are bound. Cotton's :: escape is for attributes on a c- tag; the Alpine bindings below sit on plain HTML, which cotton passes through untouched. The container is a singleton the base template renders once, so it takes no props: it owns its own corner of the viewport and needs no placement from a caller. {% endcomment %}
