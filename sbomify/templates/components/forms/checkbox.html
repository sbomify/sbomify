{% comment %} A checkbox and its label, in plain Tailwind utilities. The label wraps the input, so the text is part of the hit area and no id is needed to tie them together; id is still rendered when name or id is given, for a label elsewhere on the page to point at. The control itself is c-forms.checkbox-input, which every state is drawn on; this file adds the label around it and nothing else. A row that is its own control reaches for that component directly. class lands on the wrapping label (layout) and is blanked for the control, which would otherwise take the label's layout as its own; everything else, including x-model and @change, lands on the input. {% endcomment %}
