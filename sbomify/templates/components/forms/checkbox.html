{% comment %} A checkbox and its label, in plain Tailwind utilities. The label wraps the input, so the text is part of the hit area and no id is needed to tie them together; id is still rendered when name or id is given, for a label elsewhere on the page to point at. Every state is drawn on the real input: checked, indeterminate, focus and disabled are pseudo-classes, never a styled sibling. The control is appearance-none, so the browser's own tick and dash never render and both are drawn here; the indeterminate mark is listed after the tick because Tailwind emits it later and an indeterminate box is usually checked too. The box stays 1.25rem while an invisible ::after stretches the touch target to 44px. class lands on the wrapping label (layout); everything else, including x-model and @change, lands on the input. {% endcomment %}
