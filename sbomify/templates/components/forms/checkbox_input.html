{% comment %} The checkbox control on its own, with no label around it: the box a row draws itself, where the row already carries the role, the checked state and the keyboard handling and a nested label would forward a second click into it. For a checkbox with its own text use c-forms.checkbox, which nests this. Every state is drawn on the real input: checked, indeterminate, focus and disabled are pseudo-classes, never a styled sibling. The control is appearance-none, so the browser's own tick and dash never render and both are drawn here; the indeterminate mark is listed after the tick because Tailwind emits it later and an indeterminate box is usually checked too. The box stays 1.25rem while an invisible ::after stretches the touch target to 44px. {% endcomment %}
