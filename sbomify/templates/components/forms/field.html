{% comment %} A field: the label, the control, and the one line of help under it. The control is the slot, so the same wrapper holds an input, a select, a textarea or a group of checkboxes without knowing which. In a stacked field, an error replaces the hint. The message is written here; the border that goes with it belongs to the control, which takes state="error", so the two live where they are read from. for names the control the label points at, and is passed straight through to c-forms.label. horizontal puts the label and hint beside the control in a divided settings row. Rows stack on small screens. The control remains the same shared input, select, toggle or action, and errors stay beside the control they describe. The parts below are wrapped in a with block that blanks class: the field's own class is layout for the field, and the label and the help line would otherwise inherit it and repeat that layout on every row. {% endcomment %}
