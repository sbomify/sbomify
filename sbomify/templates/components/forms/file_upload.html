{% comment %} The drop zone, in plain Tailwind utilities: a dashed panel that is also the label for a file input, so clicking anywhere on it opens the picker and the keyboard reaches it through the input. The drag state is the caller's, because only the caller knows what a drop does. Pass active, the Alpine expression that is true while a file is over the zone, and the drop handlers themselves (@dragover.prevent, @dragleave.prevent, @drop.prevent) as attributes; they land on the panel. active swaps the whole border-and-background recipe rather than adding to it: border style, border colour and background would otherwise each have two utilities on the element at once, and Tailwind settles that by stylesheet order, not by which one Alpine added last. The main line is the slot; hint is the second, quieter line. on_change is the Alpine handler for the picked file, which belongs on the input rather than on the panel. {% endcomment %}
