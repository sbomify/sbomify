{% comment %} Rows of key and value text fields, with a remove button per row and an add button under them. Built for custom metadata on products and components: free-form string pairs a workspace defines for itself. model is an Alpine expression naming an array of { key, value } objects in the caller's scope; the rows bind to it, so the caller owns the data and decides how to save it. With name set, each row also posts as repeated name_key and name_value fields, so an HTMX form can submit it without any script. max caps the rows the add button will create, to match the server limit. label is the group's accessible name. Empty rows are allowed while editing; the server drops a row whose key and value are both blank. {% endcomment %}
