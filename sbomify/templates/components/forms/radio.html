{% comment %} One radio and its label, in plain Tailwind utilities. Radios in a group share a name, so there is no unique id to point a label at: the label wraps the input instead. Checked is drawn by thickening the real input's border into a ring, so the mark cannot drift from what submits. The dot stays 1.25rem while an invisible ::after stretches the touch target to 44px. x_value is the Alpine expression form of value, for a radio in a list the browser builds. It replaces the static attribute rather than adding to it: Alpine only writes a bound value onto a radio that has no value attribute of its own, so emitting both leaves the control holding the empty string and x-model never finds its match. {% endcomment %}
