{% comment %} A search field with the magnifier inside it and a clear button on the right. The input comes first in the DOM and carries peer, so the icon and the clear button react to it in CSS alone: the icon takes the brand colour while the field has focus, and the clear button fades in once there is something to clear. Both sit on top of the field, so the order they are written in does not move them. model names the Alpine property the field reads and writes, the way the date picker takes value_binding. Given one, the field is bound to it and the clear button empties it; without one the field is a plain input driven by whatever attributes the caller passes (an hx-get, a form submit). Attributes land on the input, which is the thing a caller configures; class lands on the wrapper, which is the thing a caller sizes. hint reserves room on the right for a trailing shortcut hint, the navbar's ⌘K, which goes in the slot along with anything else that sits over the field. {% endcomment %}
