{% comment %} The select, in plain Tailwind utilities. The native control is kept and the browser's arrow is replaced by the chevron the design system draws, so the option list stays the platform's own. options is a list of {value, label} built in the view, because a list is data, not content. The slot takes over for callers that render their own options (an Alpine template, an optgroup). Two conditional segments, each complete on its own: size owns width, padding and font-size; the colour segment owns background, border, ink and the focus ring together. accent is the state the select holds, tinting it the way a badge of the same value would; state is validation and outranks it, so an errored status select reads as an error. The focus border stays primary throughout. {% endcomment %}
