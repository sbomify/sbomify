{% comment %} The multi-line input, in plain Tailwind utilities. It grows vertically only, so a long answer never breaks the column it sits in. The text is a prop, not a slot: whitespace inside a textarea is part of the value, and a slot would hand it the template's indentation. state is one conditional segment holding the resting border colour and the focus ring together, exactly as on c-forms.input, and data-state is its runtime twin for an editor whose validity is only known in the browser. {% endcomment %}
