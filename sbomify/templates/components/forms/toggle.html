{% comment %} A switch and its label, in plain Tailwind utilities. It is a checkbox: the track and the knob are the real input and its ::before, so the state the user sees is the state that submits. Use it for a setting that takes effect on the spot; use c-forms.checkbox inside a form that is saved as a whole. The label dims itself from the input's own disabled state through :has(), so there is nothing to keep in sync. {% endcomment %}
