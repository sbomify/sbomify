{% comment %} One tile in a choice group: a real radio, hidden but still focusable and still submitted, wearing the icon and the accent that the same value wears elsewhere, so picking "Critical" here looks like the Critical badge it produces. Selection is painted from :has(:checked), so the highlight cannot drift from what submits. accent is a prop rather than a file: it names a badge family, of which there are eleven counting the severity scale, and it sets one custom property that the border, the wash and the icon all read, so a file per accent would restate the same recipe eleven times. It renders as one conditional segment. The label text is the slot. selected is the group's current value: a tile checks itself when its value matches, which is how one value reaches a list of tiles. Full-contrast text on the tint is deliberate: amber and cyan accents cannot carry label text on their own wash in either theme, so the accent stays on the icon, the border and the fill. x_name, x_checked, x_disabled and x_click are the Alpine-expression forms of the same-named attributes, for a tile whose group and state the browser works out (a row rendered from JSON, a status the page derives). They are props because attrs land on the label, and these belong on the real input: the checked look is painted from :has(:checked), so a bound tile has to drive the control itself rather than a class. x_name replaces the static name rather than adding to it, so a page of bound tiles is never briefly one radio group before Alpine runs. Everything else the caller passes, ::style and ::title included, still reaches the label. {% endcomment %}
