{% comment %} The vertical page layout. A frame owns the 1.5rem gap between its children; headers, navigation and content supply no external margins. Hidden elements and dialogs outside normal flow do not consume a gap. The app canvas uses this by default. Use another frame when a group needs its own container, such as an HTMX replacement root or a form page with a narrower width. IDs, Alpine state and HTMX attributes stay on the frame's real element. Nested groups may use flex/grid gaps for a denser internal layout. {% endcomment %}
