{% comment %} The header every main page opens with: a mark, the page title, one line under it, and the page's actions on the right. Actions are the slot, because they are real controls (buttons, a filter form, a menu) and a parameter cannot describe them; a page with no actions just closes the tag. Put it above the page's content stack, not inside it. The gap under the title belongs here, so every page has the same one; inside a space-y-* stack pass flush, which replaces that gap instead of fighting it with a caller class. mark picks the mark's shape: the icon chip by default, the round avatar with mark="avatar". Both read their tint from an inherited custom property, so a one-off colour is still style="--chip-accent: var(--color-warning)" (or --avatar-accent) on the header itself. breadcrumbs is a list of {label, url} from the view, and renders where the subtitle goes, through c-navigation.breadcrumbs. The avatar mark is c-avatar wearing the page's icon, so the round mark has one recipe wherever it appears. The named meta slot sits on the title's own line, after the copy chips: a status the title is qualified by rather than an action, such as the stale badge on a component whose SBOM is past its freshness window. Actions belong in the default slot, on the right. {% endcomment %}
