{% comment %} Every app page starts with the same unadorned title, optional subtitle and actions. The parent c-layout.frame owns the gap before navigation or content; this header only arranges its children and supplies no external margins. The default slot holds real action controls. copy_values and the named meta slot sit beside the title, for identifiers and statuses. breadcrumbs replaces the subtitle on detail pages, and editable_item_type with editable_item_id keeps the same title editable without a second header implementation. description is optional supporting text. Long descriptions can be expanded without truncating the page title. Its state is scoped to the description so callers can still bind their own Alpine state to the header. {% endcomment %}
