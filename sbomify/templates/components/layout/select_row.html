{% comment %} A list row that is clickable in full: clicking anywhere in it toggles the control it contains, so the hover has to say so. The selected state is painted from :has(:checked) rather than a class, so it cannot fall out of step with the control, and the row keeps a real checkbox for the keyboard and for form submission. The row click is a pointer convenience on top, and it stands aside when the click already landed on something interactive. The control and the body are both the slot: a checkbox belongs to the form set, not to the row, and the row toggles the first input it finds. Alpine state that a row needs (a delete modal, an x-model) goes in the x_data prop, so the row carries one x-data attribute rather than two. toggle_ref names the x-ref of the control the row toggles, for a row whose body holds inputs of its own: a plugin row with its config fields open would otherwise toggle the first of those rather than the row's own switch. Without it the row clicks the first input it contains, which is right whenever the control is the only one. disabled drains the colour from the row. What actually blocks it is the control's own disabled attribute, which is what :has(input:disabled) reads, so the two can never disagree. It desaturates and does not fade. opacity on the row composites every descendant against the page, text included, and a row that explains why it is unavailable needs that explanation readable: at opacity-50 the plan-required badge measured 1.4:1 and the description 2.0:1 against a 4.5:1 AA floor. grayscale carries the same "inert" read for free, because the filter matrix is the luminance matrix -- it moves hue, not relative luminance, so every pair in the row keeps the contrast it was designed with. Neither opacity nor filter can be cancelled by a descendant, so anything the row must keep legible has to be something the row never dimmed in the first place. divided gives a list of rows a shared hairline separator, leaving the last row open so it can sit directly inside a card without another bordered box. {% endcomment %}
