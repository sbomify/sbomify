{% comment %} The shared stat card: a value, a sentence-case label and an optional icon. compact changes density only. Every size uses the same surface and hierarchy. value groups numbers with thousands separators and accepts formatted text; x_value binds an Alpine expression to the real value element. Zero values use neutral ink and tint in both cases. unmeasured is for a metric that has nothing to count yet, which is not the same as counting nothing. A security card whose components have never been scanned would otherwise print a confident 0 on the surface a reader acts on. It renders the neutral no-value dash and takes the zero ink, because an unmeasured card must never look alarming. unmeasured_label replaces the label rather than hiding behind it: a bare dash tells a sighted reader nothing, and an explanation only a screen reader gets leaves the people the state is for worse informed than the people it is not. The optional slot holds a change indicator beside the value. Accents include semantic colours and the severity scale, so pages never supply a colour recipe. Value and icon ink use those tokens directly, never a mix with the text colour. Each card is its own description list and can sit in any grid or flex layout. loading replaces the value and label with decorative skeletons in the same grid, for c-feedback.loading-stats.
