{% comment %} The instrument readout: a still surface, tabular numerals and a flat tinted icon chip. Containers do not move, so there is no hover lift. The parts go in the slot as c-layout.stat.label and c-layout.stat.value, with the delta on the value's baseline inside a c-layout.stat.row. accent is a prop, not a file: it sets one custom property that the icon and the compact number read, so a file per accent would carry no recipe of its own. compact is the dense strip above a table: the number over its label, centred, and the number in the card's accent. It retunes its parts by setting the custom properties they read, the way the stylesheet did it with descendant selectors, so the parts of a compact card never repeat "compact" at the call site. The icon is the icon chip's tint at this card's own radius, which is why it is written out rather than nested: c-chips.icon-chip owns a radius per size, and a second one from here would leave two on the same element. {% endcomment %}
