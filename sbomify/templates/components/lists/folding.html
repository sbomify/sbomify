{% comment %} A bulleted list that folds past `limit` items. Built for an advisory's affected versions, which once ran as one comma-joined line inside a chip and off the side of the sidebar when an advisory named a few dozen. One item per line keeps long identifiers readable, and folding keeps a long list from pushing the rest of the column out of view. The fold is a native
after the list, and the folded items show while it is open, through :has(). No Alpine: the toggle works before scripts load and without them, and the browser reports its expanded state to screen readers. The slot, when given, is a heading above the list. `items` is a list of strings, `limit` how many show before the toggle (default 5), `label` the list's accessible name. Items wrap at spaces first and split a long token only when nothing else fits, so an interval reads whole and a SHA cannot overflow. {% endcomment %}
