{% comment %} The dialog, in plain Tailwind utilities. It teleports to the body so no scrolling or clipping ancestor can trap it, and it is driven by an Alpine expression the caller owns: show names the boolean that is true while the dialog is open, so one x-data can hold several dialogs. The default slot is the body; the named footer slot adds the footer band, which is where the actions go. A form may wrap body and footer: the [&>form] segment puts it into the panel's flex column, so the body still scrolls and the footer stays pinned under the 90vh cap. Size is one conditional segment on the panel, so two max-widths never land on it. The backdrop is the click catcher, and it carries a light wash of the page background: enough to sit the dialog above the page rather than in it, not enough to black the content out. It is mixed from --color-background so it reads the same way in both themes. role is a prop rather than a passthrough attribute because the element already carries one: a second role in attrs would be a duplicate attribute the browser ignores. Pass role="alertdialog" for a dialog that interrupts to confirm something destructive. teleport="false" leaves the dialog where it was written. HTMX wires hx-* on the content present at swap time and the teleport moves the dialog out after that, so a dialog living inside an HTMX-swapped partial loses its form handling and falls back to a native submit. Only the wrapper differs between the two, so the panel below is written once and never copied. close is the expression that shuts the dialog, and it defaults to setting show to false, which is right whenever show is a boolean. A dialog whose open state is the thing it acts on — a row held in removeTarget, open while it is not null — passes its own, because "removeTarget !== null = false" is not a statement. The three ways out (escape, the backdrop, the close button) all run it, so they cannot drift apart. {% endcomment %} {% firstof close show|add:" = false" as dismiss %} {# djlint:off #} {% if teleport != "false" %}{% endif %} {# djlint:on #}
