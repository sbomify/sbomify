{% comment %} One section of an accordion: a trigger row and the panel it reveals. label is the trigger text, or pass a label slot for a richer row. state is the Alpine expression that reads true while the section is open; it drives aria-expanded, turns the chevron over and shows the panel. The caller supplies the click handler that flips it, because only the caller knows whether the stack allows one open section or many, so attributes land on the trigger, which is the element a caller means. Without a state the section simply stays open, which is what a page with no Alpine on it wants. label_class is layout for the trigger's label, and only for it, the same prop c-navigation.stepper-step gives its caption. A row that is a chip, a name and a progress bar has to reach the trigger's full width and space its own parts, and the label is a flex item of the trigger, so `flex flex-1` there is the only place that can say so. The label states no layout of its own, so nothing stacks. {% endcomment %}
