{% comment %} One section of an accordion: a trigger row and the panel it reveals. label is the trigger text, or pass a label slot for a richer row. state is the Alpine expression that reads true while the section is open; it drives aria-expanded, turns the chevron over and shows the panel. The caller supplies the click handler that flips it, because only the caller knows whether the stack allows one open section or many, so attributes land on the trigger, which is the element a caller means. Without a state the section simply stays open, which is what a page with no Alpine on it wants. {% endcomment %}
