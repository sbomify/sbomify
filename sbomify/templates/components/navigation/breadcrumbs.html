{% comment %} The page trail. items is a list of {label, url} built in the view, oldest first; the last crumb is the current page, so it renders as text even when it carries a url, and it is the one that says so with aria-current. separator is the Font Awesome class of the chevron between crumbs. A crumb may also carry icon and title, which the public trails use: the mark beside the label, and the full name of a label the trail had to shorten. The icon brings the row layout it needs with it, so a trail of plain labels renders exactly as it did before there were icons. {% endcomment %}
