{% comment %} One section of an accordion that the browser opens by itself: a details/summary pair, for a page with no Alpine on it. It is c-navigation.accordion-item's twin and carries the same recipe, so the two read identically inside the same c-navigation.accordion; only what drives the open state differs, which is why this is a file and not a prop. Native state uses the native attribute: the panel shows because the details element is open, and the chevron turns on group-open, so the mark can never drift from the state that drives it. open renders the section open on arrival. label is the trigger text, or pass a label slot for a richer row (an icon and a caption). label_class is layout for that label and only for it, as on c-navigation.accordion-item. The summary's list marker is dropped by display:flex, which is how the stylesheet's trigger dropped it too. The compact size is the bare font-size, not text-sm: the stylesheet's compact trigger set a size and inherited its line-height, which is 1.5, and text-sm carries 1.4286 — a pixel shorter on every row, which a dialog sized around it then moves by half a pixel. {% endcomment %}
