{% comment %} A page control for a table that pages in the browser. c-navigation.pagination is the server-rendered pager, where the view knows the current page and every link is an href; this is its Alpine twin, for a table whose current page is client state. The caller binds state, never classes: … The active recipe hangs off data-active and the unavailable one off the real disabled attribute, so the look can never drift from the state that drives it. Recipes match c-navigation.page-link, which the server-rendered pager uses. {% endcomment %}
