{% comment %} One cell of a pager: a page number, the current page, or a previous/next chevron. c-navigation.pagination builds a whole pager out of these. With an href it renders an anchor; without one it renders the span the current page is. The two branches differ only in element and in how each spells its dead state: a link can never match :disabled, so its real state is aria-disabled, exactly as the tw-pagination-btn rules had it. active, disabled and the plain state are one conditional segment, so the hover utilities are simply absent where the CSS excluded them with :not(). nav is the smaller type the chevrons take, and label is the accessible name they need. {% endcomment %} {% if href %} {{ slot }} {% else %} {{ slot }} {% endif %}
