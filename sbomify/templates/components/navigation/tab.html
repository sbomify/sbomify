{% comment %} One tab in a tab row, a real button with the tab semantics: only the selected tab is in the tab order, and the row's arrow keys move between them. panel is the id of the panel this tab controls, so the tab is id="tab-" and the panel it points at is id="panel-". active selects it. icon is a Font Awesome class and badge a short count, both of which sit in fixed places the slot cannot express; the slot is the label. Selected colour renders as one conditional segment, and the pills utilities hang off the row's data-tabs-pills, so a tab never carries two borders or two backgrounds at once. {% endcomment %}
