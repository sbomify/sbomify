{% comment %} Every tab row scrolls natively without a scrollbar. Quiet arrows appear only when its content overflows; the shared controller keeps the selected tab visible. links renders ordinary navigation links, with aria-current instead of tab semantics. Entries may carry href for server-driven pages. The tab row: a real tablist that owns the arrow, home and end key handling, so a tab set is keyboard-navigable wherever it is used. Give it a tabs list from the view ({id, label, icon, badge}) and it renders the row; leave the list off and hand-built c-navigation.tab children go in the slot. active is the id of the selected tab, which the loop below turns into the selected tab's flag. Each tab is rendered `only`, on its own props, so nothing this row holds (its class, above all) can fall through into it. The pills look is a variant file (c-navigation.tabs-pills): it swaps the recipe and marks the row with data-tabs-pills, the attribute each tab reads to drop its underline, the same descendant relationship the .tw-tabs-pills rules had. {% endcomment %}
