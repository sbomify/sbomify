{% comment %} The row-actions column, the one holding the actions menu. Wide enough for the button to sit in the cell's own right gutter, so it lines up with the toolbar above rather than crowding the shell's edge, and a fixed width so an equal-width table never hands it a full share. Narrower on a phone, where every pixel this column keeps comes out of the name beside it. as="th" renders the header twin, whose only content is the screen-reader name for a column with no visible heading; the body cell renders the slot. The two branches differ in the cell they nest and in nothing else, and both state their own gutters, so the default ones never stack against them. pinned holds the column against the right edge while the rest of the table scrolls under it. For a table wide enough to scroll, this column is often the only route to an action, and a thin scrollbar under the last row is not an affordance anyone reads. A pinned cell has to paint its own background, since the row's tint is transparent and the scrolling cells would otherwise show through it, so the resting and hover fills are stated here as opaque colours and the row marks itself group for the hover to reach.
