{% comment %} The band that appears above the table once a row is selected: how many rows are selected, a way to clear them, and the bulk actions in the slot. It reads the tableSelection state on the shell, so it goes inside the shell, after the toolbar and before the table. noun and plural name what the rows are, so the count reads "3 components" rather than "3 selected items". The actions are the page's: a bulk delete is a c-buttons.danger size="sm" with @click="confirmDelete()", which opens the shell's c-tables.bulk-delete dialog. Nothing in this band deletes on its own. The band is hidden while nothing is selected, and a hidden element announces nothing, so the count is also spoken from a status region that is always present. The padding is written px-4 py-3 rather than p-*, for the same reason as the toolbar: the public base's pre-Tailwind utilities.css carries !important p-* rules that would repad it there. {% endcomment %}
