{% comment %} The compact select a table toolbar uses: the page-size control and the filters beside the search box. Options are the slot, so the list stays with the view; attrs land on the select, which is what a page wires up (x-model="filter"). The native arrow is off and the chevron is drawn on the select itself, so the control looks the same in every browser. Its grey is a literal, as it was in the stylesheet: it is baked into the SVG, not a theme token. For a form field use c-forms.select, which is full width and taller. This one is toolbar furniture and sizes itself to its content. {% endcomment %} {% if label %}{% endif %}
