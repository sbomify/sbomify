{% comment %} The selection column, the first one in a table that offers bulk actions. It reads and writes the tableSelection state the shell keeps (x-data="tableSelection"), so a page passes the row's id and name and wires nothing else. as="th" renders the select-all box. It is checked when every row on screen is, indeterminate when only some are, and selects or clears all of them in one click. The body cell renders the row's box: value is the id a bulk action posts, label is the name the box is read out as ("Select acme-gateway-core") and the name the delete confirmation lists. A row the person may not act on passes disabled, which also keeps it out of select-all. In an x-for, x_value, x_label and x_disabled are the Alpine expressions for the same three. The boxes bind :checked and handle the click themselves rather than using x-model, because a shift-click selects the run of rows since the last one clicked, and x-model cannot see the shift key. The click and Enter stop at the box, so a row that opens or navigates on either is not also activated by it. The column is the box's width and no more. Its gutter is stated here, behind first: like the default recipe it replaces, so it outranks the cell's own padding rather than racing it in stylesheet order. The cell marks itself data-cell-select: a stacked table pins the box to the row's corner and treats the next cell as the row's subject. {% endcomment %} {% if as == 'th' %} {% elif x_value %} {% else %} {% endif %}
