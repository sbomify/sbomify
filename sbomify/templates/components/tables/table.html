{% comment %} The table, inside the box a wide table scrolls in: the overflow belongs here, never to the page body. Cells own their padding and their rules, so the table itself only sets the collapse model. fixed gives every column an equal share and centres each one between the first and the last, which is how a table with a trailing actions column keeps its left and right margins symmetric. A cell that states its own alignment (the end prop, the actions column) marks itself data-cell-end and is left alone, so a column that asked to sit right never drifts to the centre. class is layout for the scroll box; attrs land on the table. {% endcomment %}
