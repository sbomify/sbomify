{% comment %} The shell every tag shares, in plain Tailwind utilities. The bare shell is the neutral tag, so the colour variants (c-tags.primary and friends) nest this and pass their recipe through variant_class. Content, including any icon, goes in the slot; the shell's gap spaces it. removable renders the close button. label names what is being removed, for the accessible name, and remove_click carries the Alpine handler the editors wire up (@click.stop, so clicking the cross never fires the tag's own click). A tag an editor builds from Alpine names itself in the browser, so remove_label takes the expression instead of the words and binds the accessible name; the two are one branch, so a close button always has exactly one name. remove_title adds the pointer tooltip the same buttons carry. With href the shell renders an anchor, for the tags that are links to the thing they name (a component under a product). It arrives without an underline, as every tag does. A link tag takes no close button: removing it and following it are different gestures. {% endcomment %} {% if href %} {{ slot }} {% else %} {{ slot }} {% if removable %} {% endif %} {% endif %}
